## CutLinear-optimizerGUI

Этот проект является продолжением проекта [CutLinear-optimizer](https://github.com/zhuravlev-artem/CutLinear-optimizer), с реализацией графического интерфейса. Графический интерфейс реализован на языке Python и библиотеке Kivy.

#### Установка
- Для использования, установить библиотеку Kivy
```bash
$ pip install kivy
```
- распаковать архив в отдельную папку
- Проверьте наличие прав на запись в эту папку в меню ПКМ в «свойствах»

#### Инструкция
После распаковки архива, для запуска программы нажмите двойным щелчком по файлу `CutLinear-optimizer.py`. Перед вами появится окно программы:
![Главное окно оптимизатора](https://github.com/zhuravlev-artem/CutLinear-optimizerGUI/blob/main/p1.png)
В первую таблицу вводятся длины и количества деталей, а во вторую – заготовок, из которых будут вырезаться детали. Затем в отдельное поле вводится ширина реза. После запуска оптимизации и завершения расчета, готовый план выведется в нижнее текстовое поле.
При вводе значений в таблицы, по нажатию ENTER, курсор переключится на следующее поле, либо на следующую строку. Чтобы временно исключить из расчета строку таблицы, необходимо убрать галочку в конце строки. Чтобы удалить строку таблицы, нажмите крестик.
![Готовый рассчет]( https://github.com/zhuravlev-artem/CutLinear-optimizerGUI/blob/main/p2.png)
